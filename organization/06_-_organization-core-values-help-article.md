# Adding and Managing Core Values

Core Values define the beliefs that guide how your team makes decisions and shows up every day. In MonsterOps, you can add and manage them directly so they stay visible and top of mind for everyone in your organization.

## How it works

Core Values live under your organization's settings. Once added, they're visible to your entire team and can be updated at any time, so your values can evolve alongside your company.

## Add a Core Value

1. Go to **Organization** in the main navigation.
2. Select **Core Values**.
3. Click **+ New core value**.
4. Enter the name of the Core Value.
5. Optionally, add a description to explain what the value looks like in practice.
6. Save your entry.
7. Repeat for each Core Value you want to add.

## Edit or delete a Core Value

Core Values can be edited and deleted at any time. Use the standard controls on each Core Value to update its name or description, or to remove it from the Organization. Deleting a Core Value is permanent.

## Things to keep in mind

- Any team member can add, edit, or delete Core Values — these actions are not restricted by permission level.
- Core Values are visible to everyone in the Organization.
- Deletion is permanent. There's no archive option for Core Values.

## Best Practices

- Keep names short and specific. A memorable value is one your team can easily recall and reference in everyday decisions.
- Add a description for each value. It helps your team understand how the value applies day to day, not just in the abstract.
- Remember that Core Values appear to all members of your organization, so write them with the whole team as the audience.
- Revisit your Core Values periodically and update them as your company grows and its culture matures.
