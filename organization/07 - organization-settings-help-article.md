# Organization Settings

Organization Settings is where Owners and Admins configure the Organization itself — its branding, terminology, the start of the work week, and API integrations. Unlike most other areas of MonsterOps, this section *is* permission-gated.

## Permissions

Organization Settings is restricted to **Owners and Admins**, in that order. Members cannot access or change Organization Settings.

This is one of the few places where permissions are enforced in MonsterOps. Most everyday actions — creating items, joining and managing teams, adding Objectives, even changing Team Settings — are open to all members.

## Open Organization Settings

1. Locate your Organization in the left-side navigation.
2. Click the **three dots** on the Organization.
3. Select **Settings**.

## What's in Organization Settings

### Organization icon

Update the icon that represents your Organization. The icon picker works the same as it does for items — color (palette or custom), and either a stock icon or one you search for. Changing the Organization icon also changes the color of the team icons in the left-side navigation.

### Organization name

Change the display name of the Organization.

### Week starts on

Set the first day of the week. This affects how weekly intervals are displayed and how KPI views, the Calendar, and meetings align with your team's work week.

### Terminology

MonsterOps lets you fully rename core item types to match your company's own vocabulary. For each of the following items, you can change:

- The singular name (e.g., "Rock" → "Priority")
- The plural form (e.g., "Rocks" → "Priorities")
- The icon used to represent the item across the product
- The default icon used when a new instance of the item is created

The configurable items are:

- **Objective**
- **KPI**
- **News**
- **Rock**
- **Issue**
- **To-do**

Changes apply Organization-wide, so they affect every user's vocabulary and visuals.

### API keys

Create and manage API keys for use with MonsterOps integrations. MonsterOps has integrations for **Zapier** and **Slack**, both of which use API keys for authentication.

API keys are sensitive credentials. Manage them carefully:

- Create a new key when you set up a new integration
- Revoke a key if it's been exposed or is no longer needed

## Best practices

- Set the **Week starts on** value before teams start tracking KPIs and running weekly meetings, so intervals line up cleanly from the start.
- Coordinate before changing terminology — these changes are Organization-wide and affect everyone's vocabulary.
- Treat API keys like passwords. Don't share them publicly, and revoke any that are no longer in use.
- Set the Organization icon and name early. They appear throughout the product and influence how your teams look in the left-side navigation.

## Things to keep in mind

- Organization Settings is one of the few permission-gated areas of MonsterOps. Only Owners and Admins can access it.
- Terminology changes apply Organization-wide and affect every user.
- The Organization icon's color affects the color of team icons in the left-side navigation.
- API keys are used for Zapier and Slack integrations.
