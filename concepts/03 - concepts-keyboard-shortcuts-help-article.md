# Keyboard shortcuts

MonsterOps includes a small set of keyboard shortcuts for creating items quickly. Shortcuts work from anywhere in the product, but they're especially useful during meetings where you're capturing items as the conversation moves.

## Item creation shortcuts

| Shortcut | Creates |
|----------|---------|
| **N** | News item |
| **R** | Rock |
| **K** | KPI |
| **T** | To-do |
| **I** | Issue |

Pressing one of these keys opens the create dialog for that item type. From there, you can fill in the required fields and save the item like you would from any other entry point.

## When shortcuts are most useful

- **Inside a meeting** — capture To-dos, Issues, and News items as they come up without breaking the flow of the conversation.
- **Quick capture from any tab** — start a new item without navigating to its dedicated tab first.

## Things to keep in mind

- Shortcuts only cover **item creation** — there are no shortcuts for archiving, deleting, or editing.
- The five shortcuts cover the workspace item types that appear in team tabs (News, Rocks, KPIs, To-dos, Issues). There are no shortcuts for Objectives, Core Values, or Org Chart roles.
- Shortcuts won't trigger while you're typing inside a text field, so they don't interfere with normal text entry.
